# S0007 — Actionable optimization suggestions

**Feature:** F0004
**Priority:** P0

## As a
User

## I want
Actionable recommendations to optimize my resume

## So that
I can update content and improve my ATS score

## Acceptance Criteria
- System returns recommendations section(s) including:
  - skills section suggestions
  - experience bullet suggestions aligned to missing skills
  - optional summary/summary bullets
- Recommendations are derived from resume/job inputs and presented as suggestions.
- LLM output conforms to a structured JSON schema (validated server-side).
