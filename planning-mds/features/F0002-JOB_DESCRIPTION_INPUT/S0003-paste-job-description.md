# S0003 — Paste job description

**Feature:** F0002
**Priority:** P0

## As a
User

## I want
To paste a job description

## So that
The system can compare my resume to the target role requirements

## Acceptance Criteria
- User can paste job description text.
- UI can submit job description together with resume text for scoring.
- Backend receives job description text without losing formatting (beyond normalization).
