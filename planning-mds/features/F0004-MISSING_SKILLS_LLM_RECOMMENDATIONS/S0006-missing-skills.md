# S0006 — Missing skills list

**Feature:** F0004
**Priority:** P0

## As a
User

## I want
A list of missing skills relative to the job description

## So that
I can improve my resume to better match the role

## Acceptance Criteria
- System returns `missing_skills` as a list of canonical skill strings.
- Each missing skill includes at least one evidence reference (e.g., matched job requirement phrase).
- UI renders missing skills clearly and groups them if applicable.
