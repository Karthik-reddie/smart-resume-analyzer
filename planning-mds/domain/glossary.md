# Domain Glossary (SKELETON)

> Populate as the PM/Architect define domain rules and terminology.

## Core Terms

- **Resume:** The candidate document provided by a user.
- **Job Description / Target Role:** The textual target requirements used for evaluation.
- **Skill Extraction:** Transforming resume content into a structured set of skills.
- **ATS Scoring:** A compatibility scoring mechanism against a target role.
- **Feedback Report:** Human-readable explanation of score components and improvement suggestions.
